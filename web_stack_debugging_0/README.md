# Web Stack Debugging 0: Give Me a Page

This project fixes a broken webstack by installing Apache and serving a page with the text "Hello Holberton".

## Requirements

- Ubuntu 14.04 LTS
- Bash script must be executable
- Apache installed and running
- Page served at `/var/www/html/index.html` with content: "Hello Holberton"

## Files

- `0-give_me_a_page` - Bash script that installs Apache, starts it, and creates the page.

## Usage

1. Make sure the script is executable:

```bash
chmod +x 0-give_me_a_page
